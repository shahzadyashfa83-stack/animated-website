# 💖 Love Proposal Animated Website

A romantic and interactive **Love Proposal Animated Website** designed to create a beautiful and memorable digital proposal experience. The website combines elegant visuals, smooth animations, and a heartfelt design to make the moment special. 💍✨

## ✨ Features

* 💖 Romantic and modern design
* ✨ Smooth animations and transitions
* 💍 Interactive proposal section
* 🌹 Beautiful visual effects
* 📱 Fully responsive design
* 🎨 Clean and attractive UI
* ⚡ Fast and lightweight
* 💻 Built with HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, animations, and responsive design
* **JavaScript** — Interactions and dynamic effects

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy the animated love proposal experience. ❤️
